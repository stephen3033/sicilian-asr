# Sicilian LM feasibility

`diagnostics.json` reports temporary n-gram count probes on separately classified auxiliary text. A final Sicilian LM has not been trained, and its order is not predetermined. The verified DOS24 text cohort is empty; auxiliary perplexities must not be presented as DOS24 performance.

See [the feasibility assessment](../../../docs/scn-lm-feasibility.md) and [reproduction commands](../sources/README.md).
