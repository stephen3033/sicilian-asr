# Sicilian pronunciations

The POC builds its lexicon from acquired WikiPron observations and provisional Sicilian rules in `lexicon.py`. Generated bundles stay in `.cache/scn/models`; `outputs/scn_poc/pronunciations.json` records full IPA, projected ZIPA IDs, provenance and exclusions.

`ipa-compatibility.json` is the earlier inventory audit. It measures representability, not linguistic correctness. No independently validated gold lexicon has been established. See [pronunciation evidence](../../docs/pronunciation.md) and the [POC study](../../docs/poc.md).
